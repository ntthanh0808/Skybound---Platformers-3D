# 3D Platformer Game - Android

Một game 3D platformer được phát triển trên Unity cho nền tảng Android.

## 📱 Thông tin dự án

- **Nền tảng**: Android
- **Engine**: Unity
- **Thể loại**: 3D Platformer
- **Trạng thái**: Đang phát triển

## 🎮 Tính năng

- Di chuyển và nhảy nhân vật trong không gian 3D
- Hệ thống nền tảng di động
- Thu thập crystal
- Âm thanh và hiệu ứng
- Tối ưu cho thiết bị di động Android

## 🛠️ Công nghệ sử dụng

- Unity Engine
- C#
- Unity Input System
- Unity Physics System

## 📋 Yêu cầu hệ thống

### Để phát triển:
- Unity Editor (phiên bản được khuyến nghị: 2021.3 LTS trở lên)
- Android SDK
- JDK

### Để chơi:
- Android 5.0 (API Level 21) trở lên
- 100MB dung lượng trống

## 🚀 Cài đặt và chạy

1. Clone repository này:
```bash
git clone https://github.com/[your-username]/platformers-3d.git
```

2. Mở project trong Unity Editor

3. Chọn platform là Android trong Build Settings (File > Build Settings)

4. Cấu hình Android SDK path nếu cần

5. Build và chạy trên thiết bị hoặc emulator

## 📂 Cấu trúc thư mục

```
Assets/
├── Animations/        # Animation clips và controllers
├── Audio/            # File âm thanh
├── Materials/        # Materials cho 3D objects
├── Models/           # 3D models
├── Prefabs/          # Prefabs tái sử dụng
├── Scenes/           # Game scenes
└── Scripts/          # C# scripts
```

## 🎯 Hướng dẫn chơi

- **Di chuyển**: Sử dụng joystick ảo hoặc touch controls
- **Nhảy**: Chạm nút nhảy
- **Mục tiêu**: Thu thập tất cả crystal và vượt qua các chướng ngại vật
